Silnik analizy AI (Ollama Local / Gemini API) i automatyzacja
Przy Ollama Local transkrypt krąży wyłącznie po localhost (strona → Local Engine 8765 → Ollama 11434) — nic nie wychodzi do internetu. Gemini wymaga klucza API. Ollama Local wymaga uruchomionego start_engine.bat.

Jak użyć Ollama Local
  1. Pobierz i zainstaluj Ollama dla Windows (po instalacji działa w tle).
  2. Otwórz PowerShell lub CMD i wpisz: ollama pull qwen2.5:7b
  3. Możesz sprawdzić model: ollama run qwen2.5:7b
  4. Uruchom local-engine/start_engine.bat — Skryptorium łączy się z Ollamą przez lokalny silnik (proxy, omija CORS).
  5. Kliknij Sprawdź Ollama.
  6. Wybierz Ollama Local jako silnik analizy i wykonaj analizę transkryptu.
Trasa danych: strona → Local Engine (127.0.0.1:8765) → Ollama (127.0.0.1:11434). Wszystko zostaje na Twoim komputerze.

Brak klucza Gemini API
Klucz trzymany wyłącznie lokalnie w tej przeglądarce (localStorage). Nie trafia do eksportów, wpisów ani backupu — używany tylko do wywołań Gemini API. Bez klucza wszystkie sekcje można wypełniać ręcznie, a transkrypcja działa normalnie.
